## 使用需求

- MuMu 模擬器 12，解析度 1280×720，幀率不低於 60
- 國際服，遊戲語言為简体中文、繁體中文、English 或 한국어（한국어要把任務設定裡的「遊戲語言」選成 한국어；導航靠辨識介面上的文字，其他服認不出按鈕）；或日服（「遊戲語言」選「日本語（日服）」，用戶端要從 Google Play 安裝，切換帳號只限國際服）
- 遊戲內「節奏圖示速度」保持 5.00。每局開始前會核對，不一致只在日誌裡警告，按鍵時機會整體偏移；開了「隨機 GREAT」時偏移會把 GREAT 變成 GOOD，請務必保持 5.00（其他流速需要先在命令列裡重新校準）
- 遊戲內 MV / 背景關閉，或換成較暗、不會動的背景。背景一直在動會讓開局同步失敗或不準
- 特效、演出等級不強制，但目前只在調低的設定下測過。電腦配備較弱時建議調低，模擬器幀率會更穩
- 換電腦或重新安裝後，先用低難度打一兩首，看日誌裡有沒有同步失敗或流速警告
- 遊戲沒開啟時勾選「啟動遊戲」（排在最前面）；其他任務從主畫面、自由演出的選曲頁或演出結算頁開始
- 「AP補完」會暫時修改選曲頁的分類和篩選，正常結束後會改回去。中途停止時不會改回，可以手動改，下次「隨機」選曲時也會自動把「遊玩狀況」改回「不指定」
