# 命令行

不用图形界面时，从源码安装后用命令行运行。各任务、选项的含义见[使用说明](使用说明.md)。

## 从源码安装

需要 Python ≥ 3.11。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .[dev]
```

### OCR 模型

界面导航用 MaaFramework 的 OCR。下载模型到 `resource/model/ocr/`：

```bash
python tools/fetch_ocr.py
```

模型是 [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) 的 PP-OCRv6 small（Apache-2.0），用 [MaaCommonAssets](https://github.com/MaaXYZ/MaaCommonAssets)（MIT）转好的 ONNX 版本。脚本固定版本、校验文件，并一起下载两边的许可证。它能读日文曲名，中英文按钮也比旧的中文模型读得准。只手动演奏（`play` 命令）不需要 OCR 模型。

游戏语言是 한국어（`loop.ocr_model: ko_kr`）时另外要用 PP-OCRv3 韩文识别模型。第一次用到时自动下载到 `resource/model/ocr/ko_kr/`，也可以用 `python tools/fetch_ocr.py --model ko_kr` 提前下好。发布包里不带这个模型。

## 配置

```bash
ournotes-auto init-config          # 生成包含全部默认值的 config.yaml
```

也可以复制 [config.example.yaml](../config.example.yaml)（只列出常用项）为 `config.yaml` 再修改。未写出的项使用默认值，全部参数与说明见 `ournotes_auto/config.py`。

至少要确认两项：`device.instance`（MuMu 多开器里的实例编号）和 `device.mumu_path`（MuMu 安装目录）。日服另外把 `device.package` 设成 `com.bushiroad.sirius`（默认是国际服的 `com.bilibili.sirius.official`；模拟器里装的是国际服 Google Play 版 `com.bilibili.sirius` 时会自动改用它，不用改）。

## 使用

```bash
# 全自动连续演奏（从任意自由演出相关画面开始，会自己导航到乐队确认页）
ournotes-auto run                          # 按配置
ournotes-auto run -n 3 --mode random -d expert   # 随机选曲、EXPERT、打 3 局后停止
ournotes-auto run --watch-combo --record   # 调试：日志里列出断连处的音符；同步失败时保存截图到 debug/sync
ournotes-auto run --until-lb-empty --lb-cost 3             # 清体力：打到 LB 用完
ournotes-auto run --until-lb-empty --wait-lb --lb-cost 3   # 挂机：用完后等 LB 恢复到 3 个再接着打，一直运行
ournotes-auto run --until-lb-empty --wait-lb --lb-cost 3 --claim-studio 4   # 挂机，开始时和之后每 4 小时领一次录音室练习
ournotes-auto run --wait-lb --lb-cost 0 --claim-daily 22:30   # 挂机不等 LB（有 LB 时每局消耗 1 个，用完消耗 0 接着打），每天 22:30 领一次日常
ournotes-auto run --until-lb-empty --lb-cost 3 --lb-refill 30   # 清体力，LB 不足时用道具里的饮料补充，最多补 30 个（0 为直到用完）
ournotes-auto run --challenge --mode rotate              # 挑战演出（活动期间）：每局 200 CP，轮流打每首歌，打到 CP 不够为止
ournotes-auto run --challenge --challenge-cost 1600 -n 3 # 挑战演出，每局 1600 CP（奖励 ×8），打 3 局
ournotes-auto run --challenge --mode ap_first           # 挑战演出：先打 EXPERT 还没 AP 的歌，都 AP 了再轮流打
ournotes-auto run --arena                                # 激奏舞台：不换乐队，每局消耗按配置，一直打（-n 限局数）
ournotes-auto run --arena --arena-band rotate --arena-games 2 -n 10   # 激奏舞台：从当前乐队开始每个乐队打 2 局再换下一个，共 10 局
ournotes-auto run --arena --arena-band mygo --until-lb-empty --lb-cost 3   # 激奏舞台：换到 MyGO!!!!! 打，打到 LB 用完
ournotes-auto run --arena --until-lb-empty --wait-lb --lb-cost 3   # 挂机（激奏舞台）：LB 用完后在激奏舞台首页等恢复到 3 个再接着打

# 跟打：自己选歌、点开始，演奏时自动打歌（不导航、不启动/重启游戏，只在结算页点 ⇄ 读 FAST/SLOW），一直运行到停止
ournotes-auto assist

# 启动游戏并进入主界面；领取日常奖励（默认除看故事、活动故事外七项全领，--jobs 只做其中几项）
ournotes-auto start
ournotes-auto switch-account user_123   # 退出当前账号，从登录记录里选账号名包含 user_123 的账号登录，然后进入主界面
ournotes-auto daily
ournotes-auto daily --jobs studio,missions,pass,limited,beginner,tgw,recruit,gifts   # 录音室练习、任务、通行证、限定任务、新手任务、T.G.W CARD、免费招募、礼物盒
ournotes-auto daily --jobs story   # 跳过没看过的乐队 / 视角 / 羁绊故事（要写明才做）
ournotes-auto daily --jobs event   # 跳过限时活动没看过的活动故事 / 视角故事（要写明才做）

# 汇总本地演奏记录（总局数、AP 过的谱面、还没 AP 的谱面、最近几局），更新统计页（累计时长、成就，完整页面是 data/stats.html）
ournotes-auto records [--recent 10]
ournotes-auto records --clear-chart-offsets   # 清除按谱面学到的 offset（全局学习值不变）
ournotes-auto stats-window   # 打开「统计与成就」窗口（已经开着就切到前面），包目录里的「统计与成就」快捷方式运行的就是这个
ournotes-auto backup export [--out 文件夹]   # 导出备份（演奏记录、运行记录、成就、学到的 offset），默认放在「文档\OurNotes-Auto」
ournotes-auto backup import [来源]   # 从备份文件、旧的包目录或它的 data 文件夹导入（合并，已有的记录不变）；不写时用「文档\OurNotes-Auto」里最新的一份
ournotes-auto notify-test   # 按 config.yaml 的 notify 发一条测试推送（推送到手机：ntfy、Server酱、Bark、webhook，见 config.example.yaml）

# 识别当前画面（调试导航）
ournotes-auto look [--save] [--ocr]

# 手动模式：停在乐队确认页，点 LIVE START 并演奏指定曲目
ournotes-auto play "迷星叫" -d expert --tap 1140,648 --tap 782,612

# 谱面
ournotes-auto charts search [曲名]
ournotes-auto charts show 100026 -d expert
ournotes-auto charts prefetch              # 预先下载全部谱面

# 截图并叠加判定线/轨道线，核对几何参数
ournotes-auto screenshot --overlay

# 修改流速后重新测量音符运动参数（停在乐队确认页，--tap 同 play）
ournotes-auto calibrate motion "迷星叫" --tap 1140,648 --tap 782,612
```

也可以用 `python -m ournotes_auto ...` 运行。Windows 终端乱码时设置环境变量 `PYTHONIOENCODING=utf-8`。按 Ctrl+C 停止。

### 选曲模式

`run` 的选曲模式（`loop.song_mode`）：

- `current`：一直打当前选中的曲目
- `random`：每局结束后点「随机选曲」。第一次换歌前会把选曲页的「游玩状况」筛选改回「不指定」，因为随机选曲只在筛选后的列表里抽。
- `ap`：全曲 AP 补完。把分类切到「全部」，按 `loop.ap_difficulties` 的顺序对每个难度筛选「未ALL PERFECT」，然后随机抽歌来打。
  - 同一首歌打了 `loop.ap_max_attempts` 次还没 AP，就不再打它。
  - 未解锁或认不出的歌直接重抽。
  - 正常结束时把筛选和分类改回原样；中途停止时不会改回。
  - 例：`ournotes-auto run --mode ap --ap-difficulties expert,hard --lb-cost 0`
- `ap_first`：所选难度优先打没 AP 的歌（抽歌规则同 `ap`），没有了就改回「不指定」随机选曲。
  - 要补多个难度时写 `loop.ap_first_difficulties`（如 `expert,hard,normal,easy`），按顺序补完再按 `-d` 的难度随机。界面里难度选「优先高难度」就是这样。
  - 例：`ournotes-auto --set loop.ap_first_difficulties=expert,hard,normal,easy run --mode ap_first -d expert --until-lb-empty --lb-cost 3`
  - 某个难度确认过没有要补的歌后，`loop.ap_done_hours`（默认 12）小时内的下次运行直接跳过这个难度，每个难度省约 10 秒。曲目目录有新曲、切换账号（`switch-account`）后照样重新检查；这期间新解锁的歌要等过了这段时间才补到，想马上补就运行一次 `ap`（每次都实际检查），或设为 0。
- `list`：按歌单（`--songs` / `loop.song_list`）依次打，打完一轮从头再来。
  - 每项是曲目 ID 或曲名（任意语言，模糊匹配），可以加 `@难度`，不加就用 `-d` 的难度；用逗号、分号或换行分隔。同名的不同版本只能用 ID 区分。
  - 把分类切到「全部」后在列表里边滚边认封面找歌，第一次找一首可能要二三十秒。未解锁、找不到的歌跳过。
  - 例：`ournotes-auto run --mode list --songs "100010, 碧天伴走@hard" -n 4`
- `rotate`：只用于挑战演出（`--challenge` / `loop.challenge`），每局结束后在挑战演出乐曲选择页选中下一首，最后一首之后回到第一首。挑战演出只能用 `current`、`rotate` 和 `ap_first`。
- 挑战演出的 `ap_first`：挑战演出的乐曲选择页没有筛选和随机选曲，改为从选中的歌往下逐首看右侧面板有没有 ALL PERFECT 标记，打第一首没 AP 的（同一首打 `loop.ap_max_attempts` 次还没 AP 就不再打）；`loop.ap_first_difficulties` 的用法同上，都补完了按 `-d` 的难度轮流打每首歌。

挑战演出（`--challenge`）每局消耗 `game.challenge_cost`（`--challenge-cost`，200 / 400 / 800 / 1600，默认 200；null 为不改游戏里的设置）挑战pt，不消耗 LB，打到 CP 不够一局为止，所以不能和 `--until-lb-empty`、`--wait-lb`、`--lb-refill` 一起用。

激奏舞台（`--arena` / `loop.arena`）：转盘定歌，只打 EXPERT，不跳过，`play.touch.great_ratio` 至少按 0.01 算（多人对局不用 AP）；`--lb-cost`、`--lb-auto`、`--lb-refill`、`--until-lb-empty`、`--wait-lb` 的用法同自由演出，在激奏舞台首页的「消耗LB」里设置。`--arena-band`（`loop.arena_band`）选乐队：`current`（默认）不换；`mygo` / `avemujica` / `mewtype` / `millsage` / `dumbrock` 每局前换到这个乐队；`rotate` 从当前乐队开始按游戏里的顺序每个乐队打 `--arena-games`（`loop.arena_games_per_band`，默认 1）局再换下一个。不能和 `--challenge` 一起用。每局的乐队、名次、段位分增减、加减后的段位分、消耗的 LB 和判定数记在 `data/arena.jsonl`。

单独选中一首歌（停在乐曲选择页）：`ournotes-auto select 碧天伴走 [--category 全部]`。

### 退出码

0 正常结束；1 任务失败（一局都没打成、导航出错、服务器维护等）；2 配置或运行环境有问题；130 按了 Ctrl+C。
